Install Dependencies Inside Python Container

  1. Install Kafkacat
    1. Read the instructions to install and explore the documentation.
      • https://github.com/edenhill/kcat

  2. Install kafka-python
    1. Read the instructions to install and explore the documentation.
      • https://kafka-python.readthedocs.io/en/master

  3. Install faker
    1. Read the instructions to install and explore the documentation. This library will be used to create random text later in the assignment.
      • https://faker.readthedocs.io/en/master

  1. Use the Docker Compose YML to spin up a container with kafka + zookeeper
    1. If you haven’t already, explore the documentation on Docker Compose to understand more about the docker-compose.yml file provided in the Assignment10 folder.
      • https://docs.docker.com/compose
      • https://docs.docker.com/compose/features-uses
    2. In your terminal run the following command:
        • Windows:

> docker-compose -f "C:\path\to\your\kafka-docker-compose.yml" up -d

        • Linux or macOS:

>docker-compose -f /path/to/your/kafka-docker-compose.yml up -d

 

Congratulations, you have just launched a multi-application docker container with the following:

      • https://hub.docker.com/r/bitnami/zookeeper
      • https://hub.docker.com/r/bitnami/kafka

You should now also be able to see this container running from Docker Desktop

 

  1. Verify Kafkacat is running in your Python environment:

$ kafkacat -b kafka:9092 -L  # list all topics currently in kafka

 

This should return a message like:

 

  1. Let’s send a message:

Open a new terminal tab.

$ kafkacat -b kafka:9092 -t test-topic -P  # producer

Type in 3 custom messages: your name, the date, and a random animal

Note: This command will start the producer on the next line. The default delimiter between messages is a newline (Return/Enter). When you are done, press ctrl-d to send the messages.

 

  1. Receive the message:

Open a new terminal tab.

$ kafkacat -b kafka:9092 -t test-topic -C -q  # consumer

Note: To stop the consumer, press ctrl-c.

 

You should see the messages you sent with the producer:
