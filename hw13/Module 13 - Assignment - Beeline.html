Question #2 - Retrieve 1000 Rows of Data from Foursquare in Baltimore (20 points):
  1. Understand the API: The Foursquare API supports a limit parameter to specify the number of rows per request (maximum: 50). It also supports an offset parameter to specify the starting point of the next page of data. (This link will be helpful - https://docs.foursquare.com/developer/reference/targeting-api-management)
  2. Function Requirements:

Write a function named fetch_places_data that:

      • Accepts a limit parameter (set to 20) and an unspecified max_results parameter (you determine how to handle it).
      • Iterates through the data using the offset parameter to paginate.
      • Fetches rows until a total of 1,000 rows is collected or no more data is returned.
      • Combines the results* into a single list.
              *Hint - the data is in a JSON-like structure (a list of dictionaries).

Fields to Retrieve from Foursquare Places API (1,000 restaurants total):

      • fsq_id
      • name
      • latitude
      • longitude
      • distance
      • category_id
      • category_name
      • region
      • locality
      • postcode
      • address
      • timezone
