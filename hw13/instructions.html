Data Lake and Data Warehouse

Data Engineering Practices and Principles

Assignment Overview

For this assignment you will learn to use MongoDB.

  1. The Foursquare Places API is a service provided by Foursquare that allows developers to access rich data about places around the world. It provides detailed information about millions of points of interest (POIs), including restaurants, cafes, parks, hotels, and more. This API is widely used for building location-aware applications, business intelligence, and analytics tools.

  2. Create a free Foursquare developer account (https://foursquare.com/developers/signup Links to an external site.) to receive your API credentials (Client ID and API Key). Make sure to save these credentials.

  3. Follow the instructions for getting started with the API - https://docs.foursquare.com/developer/reference/places-api-get-started Links to an external site.

  4. Create a free Databricks Community Edition account (https://www.databricks.com/try-databricks#account Links to an external site.) for the two-week trial.

    • Make sure to click the “Get started with Community Edition” link at the second page when it asks for your cloud provider (you won’t need to use a cloud provider):

  1. This project will require learning Databricks Links to an external site. and the Foursquare API Links to an external site.. There are plenty of resources on the web to help you familiarize yourself with both.

  2. Load the Jupyter Notebook file Download Jupyter Notebook file for the assignment and follow the instructions (summarized below).

 

Question #1 - Initialize Foursquare API (0 points):
  • Update the provided code with your Foursquare API key (the Spark Session has been created in the code).

Question #2 - Retrieve 1000 Rows of Data from Foursquare in Baltimore (20 points):
  1. Understand the API: The Foursquare API supports a limit parameter to specify the number of rows per request (maximum: 50). It also supports an offset parameter to specify the starting point of the next page of data. (This link will be helpful - https://docs.foursquare.com/developer/reference/targeting-api-management Links to an external site.)
  2. Function Requirements:

Write a function named fetch_places_data that:

      • Accepts a limit parameter (set to 20) and an unspecified max_results parameter (you determine how to handle it).
      • Iterates through the data using the offset parameter to paginate.
      • Fetches rows until a total of 1,000 rows is collected or no more data is returned.
      • Combines the results* into a single list.
              *Hint - the data is in a JSON-like structure (a list of dictionaries).

Fields to Retrieve from Foursquare Places API (1,000 restaurants total):

      • fsq_id
      • name
      • latitude
      • longitude
      • distance
      • category_id
      • category_name
      • region
      • locality
      • postcode
      • address
      • timezone

 

Question #3 - Convert to PySpark DataFrame (10 points):
  • Convert Python dictionary to PySpark DataFrame.
  • Add a column with today's date (YYYYMMDD) as 'load_dt'.
  • Display() the first 5 records of the PySpark DataFrame.

 

Question #4 - Create Bronze Table (20 points):
  • Create Bronze Table in the places_db database.
  • Write a Bronze table with the raw data to the places_db database in 'delta' format.
  • Query all records of the Bronze table to verify schema, displaying 5 rows.

 

Question #5 - Create Silver Table (20 points):
  • Create Silver Table in the places_db database
  • Write a Silver table with the raw data to the places_db database in 'delta' format.
    • This may require using the "overwriteSchema" option to achieve the desired table schema. Please research this option.
  • Query all records of the Silver table to verify schema, displaying 5 rows.
Silver Table Fields:
      • fsq_id
      • name
      • distance
      • category_name
      • region
      • locality
      • postcode
      • address

Question #6 - Create Gold Table (20 points):

  • Create Gold Table in the places_db database

  • Write a PySpark query to group the Silver DataFrame (silver_df) by three columns:

    • category_name: The name of the category (e.g., "Restaurant").

    • region: The state or region of the place.

    • locality: The city or locality of the place.

  • Then, calculate the following aggregations for each group:

    • num_places: The total number of places in each group (count of fsq_id).

    • avg_distance: The average distance of the places from the query location.

    • unique_postcodes: The number of unique postcodes in each group.
      Store the aggregated results in a new DataFrame named gold_df

  • Write Gold table with the raw data to the places_db database in 'delta' format.
  • Query all records of the Gold table to verify schema, displaying 5 rows.

Gold Table Fields:

      • category_name
      • region
      • locality
      • num_places 
      • avg_distance
      • unique_postcodes
Question #7 - Query the Gold Table (10 points):
  • Query the Gold Table for Analysis
    • Find categories with average distance less than 3000 meters
    • Order by num_places (descending) and avg_distance (ascending)
    • Display all records from the query.
