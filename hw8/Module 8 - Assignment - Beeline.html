Workflow Management with Cron and Airflow

Data Engineering Practices and Principles

 

Assignment Overview

In this assignment, you will learn to use Apache Airflow to create and manage Directed Acyclic Graphs (DAGs). You will build a DAG that processes data from a JSON file and generates output files based on the day of the week.

Instructions and Deliverables

1. Objective:

  • Add the DAG template to 'airflow/dags' in your Docker 'airflow' container. 
  • Load JSON data into `airflow/dags/data/`.
  • Follow the instuctions in the DAG template to extract specific fields, including the student’s name, course, and course description.
  • Save the processed output in a file that identifies whether the task was completed on a weekday or weekend.

    Example Output:

Mosko, Scott took ENG101 (Data Engineering) on a weekday

2. Output File Requirements:

  • Create an output file named `data/weekday_data.txt` if the task is executed on a weekday or `data/weekend_data.txt` if run on a weekend.
  • Only one of these files will be generated, based on the day the DAG runs.

3. DAG Structure:

  • Recreate the DAG flow as shown in the example:

  • Ensure that all tasks complete except one. For instance, if the DAG is executed on a weekday, only the weekday task should run, while the weekend task is skipped.

4. Special Considerations:

  • The `end` task in the DAG is challenging to execute. Since both weekday and weekend branches need to complete for this task to proceed, it will often be skipped unless the DAG is adjusted accordingly. You may need to research how to set this up in Airflow.
